## Project Overview
A robust, modular command-line calculator with:
- 🧮 Basic arithmetic operations (+, -, ×, ÷)
- 🔢 Decimal precision handling
- 🛡️ Comprehensive error checking
- 📝 Calculation history
- ✅ 100% test coverage
- 🔄 Property-based testing with Faker

## Features
- CLI and REPL modes
- Modular, testable design
- PEP8-compliant, fully documented code
- Rich test suite (unit, integration, property-based)

## Quick Start
```bash
python main.py
pytest tests
pytest tests --num_records=100
pytest tests --num_records=10 -v -s
```
